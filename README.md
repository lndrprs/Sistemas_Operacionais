  <summary> 1.1 Control Panel Item - CPL </summary>
  <div>

<br>

  • Arquivos .cpl são DDL's - Dynamic Link Library -, renomeadas, que implementam applets do Painel de Controle;  
  • Para verificar a listagem no computador: dir C:\Windows\System32\*.cp  

  | Arquivo | Aplicativo Painel de Controle |
  |---------|-------------------------------|
  | appwiz.cpl | Programas e Recursos       |
  | bthprops.cpl | Dispositivos Bluetooth   |
  | desk.cpl | Configurações de Vídeo |
  | firewall.cpl | Firewall do Windows Defender |
  | hdwwiz.cpl | Assistente para Adição de Hardware | 
  | inetcpl.cpl | Opções da Internet | 
  | intl.cpl | Região e formatos de data / hora / moeda |
  | irprops.cpl | Propriedades de Infravermelho | 
  | joy.cpl | Controladores de Jogos |
  | main.cpl | Propriedades do Mouse | 
  | mmsys.cpl | Propriedades de Som |
  | ncpa.cpl | Conexões de Rede |
  | nusrmgr.cpl | Contas de Usuário | 
  | odbccp32.cpl | Fontes de DAdos ODBC |
  | powercfg.cpl | Opções de Energia |
  | sysdm.cpl | Propriedades do sistema | 
  | tabletpc.cpl | Caneta e Toque |
  | telephon.cpl | Telefone e Modem |
  | timedate.cpl | Data e Hora |
  | wscui.cpl | Segurança e Manutenção | 

  </div>

  <details>
  <summary> 1.2 Microsoft Management Console - MMC </summary>
  <div>

<br>

  • MMC é um programa: mmc.exe, que funciona como uma moldura em branco para ferramentas de administração;  
  • Apenas fornece o ambiente para adição de Snap-Ins (Que seriam como "extensões").  
  • Estrutura: mmc.exe -> Snap-Ins Selecionados -> Salvos em um arquivo .msc  

  • Verificação de .msc's: - dir C:\Windows\System32\*.msc

  | Arquivo | Descrição |
  |---------|-----------|
  | azman.msc | Gerenciador de Autorização |
  | certlm.msc | Certificados do computador local |
  | certmgr.msc | Certificados do usuário atual |
  | comexp.msc | Serviços de Componentes | 
  | compmgmt.msc | Gerenciamento do Computador |
  | devmgmt.msc | Gerenciador de Dispositivos |
